Создание переносимого EXE файла:**

Открой командную строку в папке проекта (способ из предыдущего ответа) и выполни:
```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Готовый файл будет в:
```
bin\Release\net8.0-windows\win-x64\publish\ScreenPDF.exe
